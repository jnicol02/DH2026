# Snap & Quiz

This Skill uses only Cubbie's built-in capabilities. It has no scripts and needs no sign-in.

## When to use

- "Here are my bio notes, quiz me" (with one or more photos)
- "Midterm Thursday, can you turn these whiteboard pics into practice questions?"
- "Quiz me every morning on my CHEM notes"
- "Make me a study sheet from these"

Do not use it to answer graded homework, take-home exams or quizzes the student is currently taking. If the photos look
like a graded assignment, say you can help them study the topic instead.

## 1. Read the photos

1. Read every photo, PDF or document the student sent with Cubbie's ability to read files and images.
   If a photo is too blurry to read, say which one and ask for a clearer shot; keep going with the rest.
2. Ask which course or topic this is, suggesting a guess from the content ("Looks like BIO 201, cell respiration?").
3. Pull out 5 to 15 key concepts: a term, a definition, a formula, a process step or a date. Use only what is in the
   photos; do not add facts that are not there. If something on the page seems wrong, flag it rather than fix it.

## 2. Send the clean notes

Text a short summary: the topic, then the key concepts as a dash list, at most 8 lines. If there are more than 8
concepts, make a one-page PDF study sheet (concepts, definitions, 3 sample questions), send it, and text only the
top 5 concepts.

## 3. Remember the concepts

Save to Cubbie's memory, under "Snap & Quiz" and the course name: each concept with a one-line answer, and its status,
starting as "new". Keep what the student already saved for this course; add new concepts, do not overwrite them.

## 4. Offer the daily quiz

Ask once: "Want a pop quiz every morning? 8 am?" Let the student pick the time, how often, and when to stop (default:
until the exam date if they mentioned one, otherwise 7 days). Create the scheduled check-in only after they say yes.

Word the check-in so it makes sense days later on its own:
"Snap & Quiz pop quiz for <course>: pick 3 concepts from the student's Snap & Quiz memory for <course> (missed ones
first, then new, then ones not asked lately), ask them one at a time, and update each concept's status."

## 5. Run a quiz

1. Pick 3 concepts: first those marked "missed", then "new", then "got it" ones not asked in the last 3 days.
2. Ask one question per message, short answer or multiple choice (A/B/C). Wait for the reply before the next one.
3. After each reply, say right or not in one line, with the correct answer if they missed it.
   Be generous with spelling and wording; judge the idea.
4. Update memory: a wrong answer marks the concept "missed"; a right answer on a "missed" concept marks it "new"
   again; a right answer on a "new" concept marks it "got it".
5. End with one line: the score and how many concepts are still "missed" ("2/3 🎯 2 left to nail").

If the student doesn't reply, don't chase them; the next scheduled quiz picks up where they left off.

## Other requests

- "PDF" or "study sheet": make the one-page PDF from the saved concepts for that course, missed ones first, and send it.
- "Stop the quiz": cancel the scheduled check-in for that course and confirm in one line.
- "How am I doing?": counts of got it / new / missed for each course.

## Replies

Keep each reply to a few short lines, plain text, no Markdown. One question per message. A few emoji as anchors are
fine (📸 notes, 🎯 score, ⏰ schedule, 📄 PDF). Ask one thing at a time and suggest a default the student can accept
with "yes".

## When something fails

- No readable text in any photo: "I couldn't read these 📸 try a closer, brighter shot?"
- No saved concepts when a quiz runs: "No notes saved for <course> yet. Send me a photo and I'll quiz you on it."
- Memory or scheduling fails: tell the student in one line and offer to try again.
