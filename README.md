Snap & Quiz — Cubbie Skill

Snap & Quiz turns photos of class notes, slides, and whiteboards into structured summaries, daily practice quizzes, and PDF study sheets directly inside iMessage.

Overview

- Zero Friction Setup: Requires no external authentication or OAuth sign in.
- Optional Canvas Support: If the user would like, it can read tasks on Canvas so it never misses a date.
- Spaced Repetition: Remembers missed quiz questions and retests weak concepts.
- Mobile-Optimized: Designed specifically for short form iMessage reading and interaction.
